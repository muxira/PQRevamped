# Code of conduct

This is a small project about a party game. The bar is simple:

- Be decent. No harassment, no personal attacks, no bigotry.
- Critique code, not people. "This leaks a listener" beats "this is amateur hour".
- Assume good faith; most disagreements here are about a phone that behaves differently
  from yours.
- Keep issues and PRs on topic. Game-strategy threads and feature ideas for the official
  game go to the game's own channels.

Maintainers may edit, lock or close anything that ignores this — including PRs that are
technically fine but make the project unpleasant to work on.

This document follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report problems privately to the maintainer through GitHub.
